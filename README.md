# 課題 7-1: クラスの定義とインスタンスの利用

### 課題の説明
教科書のコード8-8（Heroクラス）とコード8-13（MainクラスからProg71クラスに変更する）の内容を入力し、実行例と
同じ結果が得られるプログラムを作成しなさい。
ただし、勇者の名前（String）と初期HPは実行時引数（args[0], args[1]）から与えるように変更すること。

### 実行例 (実行時引数が　　ミナト　100　　のとき)
  （注意）感嘆符は全て全角文字とする
```
勇者ミナトを生み出しました！
ミナトは、5秒座った！
HPが5ポイント回復した
ミナトは、転んだ！
5のダメージ！
ミナトは、25秒座った！
HPが25ポイント回復した
ミナトは、逃げ出した！
GAMEOVER
最終HPは125でした
```
